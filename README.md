# Avatar Tag Editor PRO (веб-версия)

Локальный инструмент для быстрой разметки тегами сотен изображений.
Работает как маленький сервер на твоём компьютере + открывается в браузере —
никуда наружу твои файлы не уходят.

## Запуск

```bash
cd avatar-tagger
pip install -r requirements.txt
python app.py
```

Открой в браузере: **http://127.0.0.1:5057**

## Что исправлено по сравнению со старой версией

- **Переименование по бакету** теперь всегда работает правильно: номер файла
  (`_N`) вычисляется заново при каждом переименовании, независимо от того,
  было ли у файла "старое" имя вида `bucket_N.ext` или произвольное. Раньше
  файлы с произвольными именами (например, скачанные из поиска) переименовывались
  без номера и затирали друг друга — это была причина "не работает".
- **Автоподсказки тегов** — теперь это настоящий автокомплит прямо в поле ввода:
  начинаешь печатать — выпадает список тегов, отсортированный сначала по частоте
  использования в текущем бакете (★), потом по общей частоте. Работает стрелками
  и Enter.
- **Пресеты бакета** упрощены до одной понятной идеи: пресет — это базовый набор
  тегов бакета. Когда открываешь неразмеченный файл из бакета, у которого есть
  пресет, теги подставляются автоматически (можно отредактировать перед сохранением).
  Кнопка "Сохранить как пресет" сохраняет текущий набор тегов как пресет бакета.
- **Свободное переименование** — простое текстовое поле с проверкой коллизий,
  без системного диалога сохранения файла.
- **Интерфейс** — тёмная тема, крупное превью, теги в виде "чипов", быстрые теги
  бакета кликабельны или по Alt+1…9, сохранение по Enter, стрелки ←/→ для навигации.

## Быстрые клавиши

- `Enter` в поле тегов — добавить тег
- `Enter` вне поля тегов — не используется, жми кнопку "Сохранить и дальше"
  (можно кликнуть или назначить свою привычку — кнопка всегда под рукой)
- `←` / `→` — назад/вперёд по изображениям (когда фокус не в текстовом поле)
- `Alt+1…9` — вставить один из частых тегов бакета

## Структура данных (как раньше, ничего не потеряется)

- `avatars.json` — теги файлов
- `.avatar_hashes.json` — хэши для защиты от дублей при скачивании
- `.bucket_presets.json` — пресеты бакетов

## О вкладке "Поиск и загрузка"

Поиск по Google/Yandex Images работает через парсинг HTML-страниц выдачи —
это как в оригинальном скрипте, но учти: поисковики могут в любой момент
поменять вёрстку или показать капчу, тогда поиск временно перестанет находить
картинки. Это ограничение самого подхода (нет официального бесплатного API),
не баг интерфейса.
